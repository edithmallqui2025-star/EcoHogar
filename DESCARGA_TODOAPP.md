# 📱 TodoApp - Descarga Directa

## ¿Cómo descargar y ejecutar?

### Opción 1: Desde Releases (Más fácil)
1. Ve a la pestaña **Releases** de este repositorio
2. Descarga `todo_app-release.apk`
3. Transfiere a tu Android
4. Instala y ¡listo!

### Opción 2: Compilar localmente
```bash
git clone https://github.com/edithmallqui2025-star/EcoHogar.git
cd EcoHogar
git checkout dev/todo-app
cd todo_app
flutter pub get
flutter build apk --release
```

El APK estará en: `build/app/release/app-release.apk`
